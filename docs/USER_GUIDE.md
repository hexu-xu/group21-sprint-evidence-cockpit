# 爱管理用户手册

## 适用范围

本手册对应 Sprint 3 待审核的技术收尾与 D5 功能补齐代码；最终发布范围以团队确认的 Release Tag 为准。项目、成员及演示账号由 README 中的初始化命令创建；用户自行注册、创建项目和管理角色尚未开放。

## 登录与角色

启动方式和演示账号见仓库根目录 README。演示密码由本机 `DEMO_PASSWORD` 设置，不随源码分发。

| 身份 | 可用操作 |
| --- | --- |
| `manager` 项目经理 | 创建和分配任务、查看本项目任务及项目概览、更新状态、调整模块、确认删除 |
| `member`、`member2` 项目成员 | 查看分配给自己的任务，更新自己的任务状态；不能查看项目整体概览或他人任务 |
| `observer` 只读管理员 | 查看项目任务及整体概览；不能创建、修改、删除任务 |
| `admin` 平台管理员 | 查看和维护项目任务及整体概览 |

## 完成一次任务协作

1. 以 `manager` 登录，在“创建任务”填写标题、描述、所属模块、优先级、截止日期和负责人。
2. 在任务看板确认任务卡、负责人和状态；切换“待完成／进行中／已完成”标签查看各状态。
3. 切换为被分配的成员账号，打开自己的任务详情，把状态改为“进行中”或“已完成”。
4. 切回 `manager`，在任务看板和“项目概览”确认状态、完成数和状态占比同步变化。
5. 如需核对权限，切换为另一位成员，确认无法看到或修改不属于自己的任务；`observer` 可以查看概览，但不能提交修改。

## 理解项目概览

“任务总数”“已完成”“进行中”“待完成”只统计当前选中的项目，三种状态数之和等于任务总数。完成率为已完成数除以任务总数；无任务时显示 0%。状态分布展示每种状态的数量和占比。

“已逾期”只统计尚未完成且截止日期早于今天的任务。“下一截止日期”是当前未完成任务中不早于今天的最早截止日。它们是任务级提示，与下面的故事进度检查点分别统计。

## 记录故事进度基线与实际结果

项目经理或平台管理员在“项目概览”中新增检查点，填写日期和计划累计完成的用户故事数。检查点按日期排列，累计计划数不能倒退。到期并有实际验收证据后，再填写实际累计故事数和证据位置；未来检查点的实际数保持空白。若事实变化，可展开该检查点修改记录。

页面以最近一个已到期检查点比较计划与实际，显示达标、超前或落后及差额；缺少实际记录时显示“待登记”，不推测结果。项目任务的完成数量不会自动折算为用户故事完成数量。普通成员不能查看或修改整体概览；只读管理员可查看，但不能修改检查点。

这一比较反映检查点上的累计交付数量，不等于项目排期、质量或发布决定已由系统自动判定。

## 常见限制

- 尚无自助创建用户、角色与项目的界面。
- 不提供任务备注、按负责人复杂筛选、历史进度趋势和按时间维度分析。
- 切换账号需要在登录页重新输入演示密码。
- 演示数据库与密码由运行者在本地维护；不要把个人真实密码填入演示环境。
